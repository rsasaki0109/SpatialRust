observations. The [complete protocol](../benchmarks/room-reference-audit-plan.json)
keeps all original accuracy, raw/causal/world/IO and full-timeline gates.
Reuse existing images and frozen native/reference modules; no new native build,
sensor download, payload copy or Cargo-cache write is allowed.

Pinned source inspection shows a source-indexed correspondence map, so a
target-unique visibility policy is not established. Seven fixed analytical
source-model cases remain distinct from actual runtime correspondence
observations. A full room reference trajectory and independent scoring will
test whether the observed native drift is also present in the public CPU model.

Reference results cannot qualify the native solver or replace any requirement
of the operational 80% goal. Implementation and results are pending.
