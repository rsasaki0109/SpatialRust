# Visual Epic 133 implementation receipt

Date: 2026-07-28

## Scope

Epic 133 establishes the backend-independent Visual contract in
`C:\Users\rsasa\Workspace\SpatialRust\crates\spatialrust-viz`.

- Borrowed SoA XYZ, RGB, scalar, line-list, and indexed-triangle views.
- Validated point styles, scalar ranges, linear colors, projections, and look-at
  cameras.
- Ordered uniquely identified layers with style/geometry compatibility checks.
- Optional zero-copy `HasPositions3` adapter behind the additive `core` feature.
- Explicit host/device residency and ordered transfer receipts with checked byte
  totals.

The crate does not allocate GPU resources, open a window, read a file, or copy
borrowed geometry. Rendering and UI dependencies remain outside this crate.
