# Visual Epic 138 receipt

Date: 2026-07-28

## Scope

- Added `spatialrust-web` as `rlib` plus WASM `cdylib`.
- Added a strict, versioned `WebViewerState` JSON envelope and browser input
  messages that reuse `ViewerController`.
- Added a WebGPU bridge over the existing explicit upload/headless renderer.
- Added bounded remote range planning, exact-range caching, WASM bindings, and
  AbortController-backed browser fetch.
- Added an executable browser smoke page under `crates/spatialrust-web/web`.

## Contract evidence

- Unknown JSON fields/versions, invalid camera/viewport, duplicate/missing layer
  identities, and invalid input fail before state revision changes.
- The WebGPU bridge renders the canonical red point to the same 64x64 headless
  target and keeps the portable state revision in the frame receipt.
- `WgpuRuntime::new_headless_async` is the wasm-safe constructor; the
  process-global shared runtime is intentionally native-only.
- Range plans sort/deduplicate requests and enforce request count, per-plan
  bytes, single-range bytes, cancellation, and cache bytes before admission.
- Browser fetch requires HTTP 206 and exact `Content-Length`; JS/WASM and cache
  copies are explicit and byte-accounted.
