# Visual Epic 137 receipt

Date: 2026-07-28

## Scope

- Added `spatialrust-lod` with a format/backend-independent indexed hierarchy.
- Added perspective and orthographic camera-frustum selection with projected
  screen error and enter/exit hysteresis.
- Added deterministic selection/request/cancel/display plans under hard point,
  upload-byte, and in-flight limits.
- Added records-backed decoded host leases, per-frame upload admission,
  cooperative cancellation, and bounded GPU residency.
- Added optional conversion of selected node bounds to a bounded COPC query.

## Contract evidence

- Hierarchies reject duplicate IDs, missing/inconsistent parents, cycles,
  unreachable nodes, invalid bounds, and zero counts/bytes.
- Selection is invariant to input child order and stable across camera jitter
  inside the hysteresis band.
- Fine children display a resident ancestor until their explicit uploads finish.
- Memory reservations release on success, cancellation, error, and drop.
- Protected GPU nodes are never evicted; failed admission leaves cache state
  unchanged; unprotected ties use generation then `NodeId`.
- Exact host, upload, GPU, eviction, and peak-memory values are in receipts.
