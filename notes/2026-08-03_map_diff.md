# Source-bound Map Diff 145D — 2026-08-03

## Scope

145D adds a renderer-independent MapDiffState, a SpatialRust-authored glTF
buffer decoder, and a feature-gated rosbag2_map_diff example. The example
compares two existing E2E run directories from the external SSD, never
reopens or copies the sensor bag, and produces a JSON state, static HTML
heatmap, and checksummed manifest. Comparison admission is independent from
calibrated mapping admission.
